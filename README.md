Interactive Portfolio Website

An interactive, game-like personal portfolio website built to showcase projects, skills, education, and achievements — designed as an engaging alternative to a traditional static portfolio page.

🔗 Live Demo: [Add your live link here, if hosted] 📂 Repository: https://github.com/Kashish-111/Intractive-portfolio

✨ Features
Game-like, interactive user experience instead of a static single-page layout
Custom JavaScript-based interactions and animations for higher engagement
Sections for Projects, Skills, Education, and Achievements, organized for easy navigation
Fully responsive design — tested across desktop and mobile breakpoints
🛠️ Tech Stack
HTML — page structure and content
CSS — styling, layout, and responsive design
JavaScript — interactivity and dynamic behavior

🚀 Getting Started

To run this project locally:

bash
# Clone the repository
git clone https://github.com/Kashish-111/Intractive-portfolio.git

# Navigate into the project folder
cd Intractive-portfolio

# Open index.html in your browser

No build tools or dependencies are required — this is a pure HTML/CSS/JavaScript project.

📱 Responsiveness

The layout adapts across screen sizes, from mobile devices to desktop, ensuring a consistent experience regardless of viewport.
